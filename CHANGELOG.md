# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.3] - 2026-01-13

### Changed
- Updated website design with premium textures and improved homepage
- Enhanced SEO across all pages with structured data
- Improved documentation consistency

### Fixed
- Footer logo visibility on dark background
- Various UI/UX improvements

## [1.0.2] - 2026-01-12

### Added
- Multiple color modes: mono, original, and palette
- Custom character sets support
- Image filters: brightness, contrast, saturation
- Floyd-Steinberg dithering
- Multiple export formats: PNG, SVG, TXT
- TypeScript definitions

### Changed
- Improved rendering performance
- Better aspect ratio handling with `autoScaleHeight`

## [1.0.1] - 2026-01-11

### Fixed
- Initial bug fixes and stability improvements

## [1.0.0] - 2026-01-10

### Added
- Initial release of ASCIIR
- Core `<ASCIIR />` component for rendering ASCII art
- `useASCIIRender` hook for accessing download methods
- HTML, SVG, and Canvas output modes
- Configurable resolution, fonts, and colors
- Export functionality for PNG, SVG, and TXT formats
- Preset character sets and color palettes
- Interactive demo application
- Comprehensive documentation
